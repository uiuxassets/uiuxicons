Added @uiuxicons/react-native: typed React Native components for iOS and Android, rendered with react-native-svg and working in Expo and bare React Native apps. Same API as the React package (variant, weight, size, color, IconProvider), plus accentColor to tint the duotone layer. Requires React Native 0.79+ and react-native-svg 15+. Import icons by path (e.g. @uiuxicons/react-native/icons/gear) to keep Metro bundles small. The docs have a new React Native section, and every icon page has a React Native snippet.
Released v0.8.13: @uiuxicons/core, @uiuxicons/react, @uiuxicons/vue, and @uiuxicons/react-native at 0.8.13, 613 icons.
