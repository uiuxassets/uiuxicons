# Security Policy

## Supported Versions

Only the latest published version of `@uiuxicons/react` and `@uiuxicons/vue`
receives security fixes. Older versions are not patched; please upgrade to
the latest release.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report privately via either:

- Email: [hello@uiuxicons.com](mailto:hello@uiuxicons.com) with the subject
  line "SECURITY"
- GitHub: [private vulnerability reporting](https://github.com/uiuxassets/uiuxicons/security/advisories/new)

Include a description of the issue, steps to reproduce, and the affected
package or site page if known.

## What to Expect

- Acknowledgement of your report within 7 days
- A fix or mitigation plan for confirmed issues, released as soon as
  practical, with credit to the reporter unless you prefer otherwise

## Scope

- The npm packages `@uiuxicons/react` and `@uiuxicons/vue`
- The build pipeline and generated assets in this repository
- The [uiuxicons.com](https://uiuxicons.com) site
